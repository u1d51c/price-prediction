# Инструкция по запуску и использованию

Сервис прогнозирует направление движения цены на следующий торговый день
для трёх активов: Brent, WTI и Bitcoin. Прогноз - один из трёх классов:
рост (up), падение (down) или без движения (flat).

Под капотом: модель RandomForest на ценовых, новостных (GDELT) и
sentiment-признаках (FinBERT). Модели хранятся в MLflow, прогноз отдаёт
FastAPI, пользователь работает через веб-интерфейс Streamlit.

---

## 1. Что нужно установить заранее

- Python 3.9+
- Docker Desktop (для MLflow и хранилища моделей)
- Зависимости проекта:

```bash
cd year_project
pip install -r requirements.txt
pip install mlflow boto3 streamlit hydra-core
```

---

## 2. Запуск (3 шага)

### Шаг 1. Поднять хранилище моделей (MLflow + MinIO)

```bash
cd year_project/docker
docker compose up -d
```

Проверка, что поднялось:
- MLflow:  http://localhost:5001
- MinIO:   http://localhost:9001  (логин `minioadmin`, пароль `minioadmin`)

### Шаг 2. Запустить сервис прогноза (FastAPI)

В новом окне терминала:

```bash
cd year_project
export MLFLOW_S3_ENDPOINT_URL=http://localhost:9000
export AWS_ACCESS_KEY_ID=minioadmin
export AWS_SECRET_ACCESS_KEY=minioadmin
PYTHONPATH=. uvicorn service.app:app --host 127.0.0.1 --port 8766
```

Проверка: откройте http://127.0.0.1:8766/healthz - должно вернуться `{"status": "ok", ...}`.

### Шаг 3. Запустить интерфейс (Streamlit)

В ещё одном окне терминала:

```bash
cd year_project
API_URL=http://127.0.0.1:8766 streamlit run service/streamlit_app.py --server.port 8501
```

Откроется браузер на http://localhost:8501

---

## 3. Как пользоваться интерфейсом

1. Выберите актив (Brent, WTI или Bitcoin).
2. При желании задайте, за сколько последних дней показать прогнозы.
3. Нажмите "Получить прогноз".
4. Увидите:
   - прогноз направления на ближайший день (рост / падение / без движения);
   - вероятности всех трёх классов;
   - таблицу прогнозов за выбранный период;
   - версию модели и время обработки.

---

## 4. Если интерфейс не нужен - запросы напрямую к API

Прогноз по активу:

```bash
curl "http://127.0.0.1:8766/predict/btc?n_days=5"
```

Документация всех методов (Swagger): http://127.0.0.1:8766/docs

Основные методы:
| Метод | Адрес | Что делает |
| --- | --- | --- |
| GET | `/predict/{asset}` | прогноз PRD-моделью (brent / wti / btc) |
| GET | `/history` | история всех запросов |
| GET | `/stats` | статистика времени обработки |
| POST | `/auth/login` | вход, выдача токена |
| DELETE | `/history` | очистить историю (нужен токен админа) |

## 6. Если что-то не работает

| Симптом | Решение |
| --- | --- |
| `/healthz` не отвечает | проверьте, что FastAPI запущен (шаг 2) |
| Прогноз возвращает ошибку 403 | модель ещё не загружена из MLflow - проверьте, что docker-контейнеры подняты (шаг 1) |
| Порт 5001 занят | на macOS его занимает AirPlay; выключите его в Системных настройках или поменяйте порт в `docker/docker-compose.yml` |
| Streamlit пишет, что сервис недоступен | убедитесь, что FastAPI работает на порту 8766 и переменная `API_URL` указывает на него |
| Нет моделей в MLflow | переобучите: `PYTHONPATH=. python -m src.training.train_with_mlflow asset=btc` |

## 7. Важное замечание о прогнозах

Прогноз носит исследовательский характер. На дневном горизонте рынок
близок к эффективному: реальный перевес модели над случайным выбором
около 2 процентов. Это не инвестиционная рекомендация.

Подробнее о методике, метриках и ограничениях - в ноутбуках папки
`notebooks/` и в файле `service/RUN_STACK.md` (техническая инструкция
для разработчика).
